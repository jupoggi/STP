SALVE O TRICOLOR PAULISTA — SITE (proposta com o visual do e-book)
====================================================================

O que tem aqui
--------------
index.html            Página principal (manifesto, pilares, lideranças, candidatos, cola, e-book).
stp-runtime.js        Pequeno script que monta a página a partir do modelo que está dentro do index.html.
assets/               Imagens, santinhos, fotos da cola e fontes (126 arquivos).
candidatos/NNN/       Uma página por candidato (38). Serve para o link do WhatsApp/Facebook mostrar
                      o santinho e o nome; ao abrir, a pessoa vai direto para o perfil no site.
_fonte/               Arquivo original da proposta e o script que gerou este pacote (não é publicado).

Como publicar
-------------
É um site estático: basta enviar todo o conteúdo desta pasta (menos _fonte, se quiser) para qualquer
hospedagem de site estático — GitHub Pages, Netlify, Cloudflare Pages, Vercel ou um servidor comum.
O arquivo index.html precisa ficar na raiz do domínio.

Para testar no computador: dentro da pasta, rode  python3 -m http.server 8000
e abra http://localhost:8000  (abrir o index.html direto com duplo clique não funciona em todos os navegadores).

Antes de pôr no ar
------------------
1. Domínio: os links de compartilhamento usam https://www.salveotricolorpaulista.com.br
   (constante SITE no fim do index.html). Se o endereço for outro, troque ali.
2. E-book: o botão "Baixar o e-book" aponta para /ebook-candidatos-stp-2026.pdf.
   Coloque o PDF na raiz com esse nome (ou troque o link no index.html).
3. Páginas antigas do Wix que o site cita: /politica-de-privacidade e /download.
   Recrie ou redirecione, senão esses links quebram.
4. Fontes: Gotham Condensed e DIN Next são fontes pagas. Confirme se vocês têm licença para uso web.
5. DNS: ao apontar o domínio para a nova hospedagem, mantenha os registros MX (e-mail) como estão.
