Painel do site

Acessos e colas montadas, direto do banco de dados do site no Wix. Página interna: não é divulgada nem aparece no Google.

Chave de API do Wix
  1. Entre no Wix com a conta dona do site e abra manage.wix.com/account/api-keys.
  2. Clique em Generate API Key, dê um nome (ex.: “Painel STP”) e escolha o site Salve o Tricolor Paulista.
  3. Em permissões, marque só Wix Data (leitura de itens). Gere e copie a chave.
  4. Cole aqui. A chave fica salva só neste navegador.

De onde vêm os visitantes

Os números vêm da coleção “Eventos STP” do Wix, gravada pelo próprio site sem cookies e sem identificar ninguém. “Visitantes” conta cada aparelho uma vez por dia; somando vários dias, a mesma pessoa pode aparecer mais de uma vez. Bloqueadores de anúncio e navegação anônima podem deixar alguns acessos de fora.
